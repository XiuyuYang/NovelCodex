# AI 味陷阱圣经

本文档是所有审校员（reviewer-ai-taste）和作家（chapter-writer）的**最高优先级参考**。
审校前必读，写作前必读。以下每一条都来自 GPT/Gemini 对已生成章节的深度审计反馈。

## 一、句式四宗罪（出现即阻塞）

### 1. 均匀短句流
连续 5+ 句都是 ≤15 字短句，主语明确、动作单一 → AI 最典型模式。
人类写作长短句天然混杂。**解法**：至少 3 个 ≥200 字长段 + 至少 3 个 ≤30 字短段。

### 2. 解释性对话
角色说出精炼的总结式表达，如「算法误差是毛边，这是手术刀」。
真实对话更含糊、有改口、有犹豫。**解法**：每段对话至少一处不完整/改口。

### 3. 重复句强化
同一句连续出现两次来增强悬疑感，如「屏幕黑了一块。屏幕黑了一块。」
**解法**：完全禁止。改用其他手法制造悬疑。

### 4. 视觉定格收尾
每章以视觉意象 + 哲学独白收尾，如「像两滴血的红灯」+「我是谁？」
**解法**：连续 3 章禁用同一收尾模式。备选：悬念钩子、对白切断、反差情绪、行动中断。

## 二、比喻与意象铁律

### 比喻密度
- 每段 ≤ 1 个比喻
- 连续 3 段必须有 1 段无比喻
- 整章每千字 ≤ 5 个比喻
- 章首段、章末段优先无比喻

### 意象不可复用
同章内同一意象系只出现一次。如「切割」系（切削面、手术刀、切得笔直）全章只允许一次。

### 安全比喻黑名单（短距内禁止复用）
萤火虫、棉花、气泡膜、涟漪、心电图、隔了一层X、海浪/潮水、镜子

### 意象回收规则
前文意象回收作情绪比喻时必须有变形或错位，不得直接重复。

## 三、感官描写多样性（强制）

- 禁止同一生理反应在 3 章内重复。如「指节发白」不可连续出现
- 禁止同一环境形容词跨章复用。如「冷白灯光」不可每章出现
- 每章至少 2 种非视觉感官（听觉、触觉、嗅觉、味觉）
- 同段内感官不超过 2 种

## 四、人物非 NPC 化

- 每个配角有 ≥1 个与剧情无关的细节（习惯、偏好、口头禅）
- 配角出场必须有自己动机，不能仅为「信息投放」
- 主角有 ≥2 个独特行为习惯或性格偏差，不能是「冷静+专业+创伤」模板
- 主角行为必须符合职业设定（法医不会在实验室失控砸器械）

## 五、段落节奏（非均匀化）

- 段落长度直方图不均匀：至少 3 个 ≤30 字短段 + 至少 3 个 ≥200 字长段
- 100-150 字段落比例 ≤ 50%（AI 默认温区）
- 干句子（纯叙述、无修辞）段落比例 ≥ 25%
- 环境-心理映射每章 ≤ 2 处，且至少 1 处反向（环境与心理对冲）

## 六、「不完美」要求（去太干净感）

- 每章至少 1 处「不必要但真实的细节」：说错话后改口、无意识动作、与主线无关但有趣的东西
- 每章至少 1 处节奏「稍微不对」：一段稍长的内心独白、或一段极短的碎碎念
- 不得出现全 5/5 的审校评分。满分 = 审校失效

## 六点五、「过于干净」即AI味（Iron Law 34，GPT审计新增）

GPT 对三篇测试章节的审计揭示了一个核心规律：**越干净越像AI，越不完美越像人**。以下是 GPT 认定的 AI 味特征，每个创作/审校环节都必须警惕：

### 六点五.1 均匀细节填充（GPT指出："每段都稳定输出同等密度"）
- 人类写作：2-3 个强细节 + 一段留白
- AI写作：每段都有可感知细节，覆盖视觉+触觉+嗅觉+听觉，节奏均匀
- **解法**：每章至少 2 段「信息稀疏段」（只推进动作，无感官修饰）。让读者有呼吸空间。

### 六点五.2 模板化节奏强化（GPT指出："一下，两下，三下"类句式）
- 人类写作：节奏多样化，不会连续用同一句式模式
- AI写作：三段式递进、行为+心理否定+状态描述反复出现
- **解法**：同一句式在同章内出现 ≥2 次即标记。多样化节奏强化方式（沉默、行动、环境回应、他人反应）。

### 六点五.3 工具化信息叙述（GPT指出："精确、有现实对照、服务于爽点逻辑"）
- 人类写作：数值和价值判断混入犹豫、怀疑、认知错误、情绪偏差
- AI写作：设定说明 + 数值支撑 + 收益计算，几乎无情绪噪音
- **解法**：任何精确数字信息旁必须有情绪噪音（主角怀疑自己算错了/犹豫要不要出手/想起不好的回忆打断计算）。

### 六点五.4 最优解行为路径（GPT指出："几乎是最优探索路径"）
- 人类写作：主角会卡住、犹豫、做无效尝试、犯错
- AI写作：发现异常→验证→观察→测试→推理→定位，一路最优解
- **解法**：Iron Law 33。每章至少 1 次次优选择（情绪干扰/信息不全/紧张导致误判）。不是逻辑缺陷，是人味。

### 六点五.5 过强的解释冲动（GPT指出："太教科书式"）
- 人类写作：直接忽略或只做一次判断，思考过程有跳跃和中断
- AI写作：把思考过程写完整，「因为…所以…因此…」完整链条
- **解法**：章节中的推理过程至少 1 处跳跃（不给中间步骤，只给结论和行动）。

### 六点五.6 愉悦感被压制（GPT指出："情绪波动被压平"）
- 人类写作：面对异常事件会有恐惧、混乱、持续性震惊
- AI写作：兴奋→继续观察，优先保证剧情推进，压制情绪噪声
- **解法**：每章至少 1 处「情绪溢出」——角色因情绪做出非最优行为（颤抖导致打翻东西/恐惧导致回避/愤怒导致口不择言）。

### 六点五.7 稳定性过高（GPT指出："没有崩句、没有设定错误、没有语气失控"）
- 人类写作：长文本多少会有轻微不一致、情绪偏差、节奏失衡
- AI写作：全程稳定，每一步都合理
- **解法**：不必刻意制造错误，但不要在审校中追求"全5分"。有些「写得不太好但很真实的句子」反而应该保留。

## 七、句式黑名单（出现即扣分）

| 类别 | 禁用句式 |
|------|---------|
| 比喻模板 | `像……一样 / 像被……的……` |
| 总结升华 | `不是A，是那种B` / `他忽然觉得，自己像X` / `隔着X，他成了Y` |
| 情绪翻译 | `像在告诉谁，X` / `溺水的人看见X` |
| 自问解释 | `那是种什么样的Z？`（全章 ≤1 次） |
| 矛盾并置 | `又X又Y`（全章 ≤1 次） |

## 八、陈词滥调黑名单

禁用：「空气中弥漫着」「命运的齿轮」「心跳像鼓点」「沉默像死寂」「眼睛里闪烁着光芒」
