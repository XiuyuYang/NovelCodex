# AI高频词黑名单（供 writer-polish / reviewer-ai-vocab 使用）

## 一级禁令（出现即违规，必须清零）

### 动作+生理反应
指节发白 / 喉结滚动 / 呼吸一滞 / 瞳孔微缩 / 身体一僵 / 后背一凉 / 心口一紧

### 神态模板
眼底闪过一丝 / 眸色一沉 / 神色复杂 / 面色微变

### 环境模板
空气仿佛凝固 / 气氛瞬间凝滞

### 抽象填充
一种莫名的 / 说不清的情绪 / 难以言喻 / 不知为何

## 二级禁令（全章累计 ≤ 3 次）

愣了一下 / 怔住了 / 若有所思 / 欲言又止

顿了顿 / 沉默片刻 / 半晌 / 下一秒 / 随即 / 忽然

## 三级弱化词（全章累计 ≤ 8 次）

几分 / 些许 / 隐隐 / 仿佛 / 似乎 / 大概
带着几分…… / 透着几分…… / 显得有些…… / 看起来……

## AI模板句（出现即违规）

他微微一怔，眼底闪过一丝复杂的情绪。
空气仿佛凝固，气氛一时间变得有些尴尬。
他沉默了片刻，缓缓开口。
不知为何，他心里隐隐有种不好的预感。
她轻轻咬了咬嘴唇，欲言又止。

## 替换思路

不写「他心口一紧」→ 写「他把手机扣在桌上，声音有点重」
不写「她欲言又止」→ 写「她张了张嘴，又把话咽回去」
不写「气氛凝滞」→ 写「没人接话，空调的风声显得特别明显」
