# 伏笔登记表

> **写入纪律**（强制规则）：
> - planner 创建每章蓝图时，必须列出本章「埋下」与「回收」的伏笔
> - 已埋未回收的伏笔即为**承诺**，必须在计划回收章节兑现
> - **「计划回收章」严禁填写"待定"**：必须给出 chXX 或 chXX-chYY 范围
> - 状态枚举：`埋下` / `强化` / `已回收` / `撤回（含解释）` / `延期`
> - 临回收前 2 章，主智能体会自动提醒 chapter-planner 准备兑现
