# memory/ — 长期记忆与设定档案

本目录是当前小说创作的**长期记忆基座**。所有跨章节稳定的事实在此统一登记。
新章节启动前，规划师与作家必须按需读取相应文件；章节完成后必须更新对应记录。

| 文件 | 作用 | 主要写入者 | 主要读取者 |
|------|------|-----------|-----------|
| `world.md` | 世界观规则、设定、专有名词 | planner | planner / writer / reviewer-consistency |
| `characters.md` | 角色档案（外形/口吻/弧线） | planner | 全员 |
| `timeline.md` | 章节末尾时间点 + 持续时间 | orchestrator（章末）| planner / reviewer-consistency |
| `foreshadowing.md` | 伏笔登记表（埋/收/状态）| planner / writer（章末）| planner（章首） |
| `locations.md` | 地点档案与空间关系 | planner | writer / reviewer-description |
| `style-bible.md` | 风格圣经：成功段落正例 + 禁用词 | reviewer-language（首章后）| writer（章首）|
| `lessons.md` | 失败用例图书馆（按维度）| 全部 reviewer（阻塞时）| writer / planner（章首）|
| `pacing-budget.md` | 字数与节奏曲线追踪 | orchestrator（章末）| reviewer-pacing |
| `planner-notes.md` | 规划师审校经验沉淀 | chapter-planner | chapter-planner |
| `writer-notes.md` | 作家审校经验沉淀 | chapter-writer | chapter-writer |

## 写入纪律

1. **追加优先于覆盖**：新事实追加，旧事实只在被现实证伪时才修改并标注「修订」
2. **章号锚点**：每条记录必须带章号前缀 `[ch01]` 或时间戳 `[2026-04-30]`
3. **简洁第一**：每条 ≤ 30 字，详细描写不入 memory（详细的去 drafts/）
4. **冲突即停**：若新写入与既有事实冲突，立刻报告主智能体，不得静默覆盖
