# 角色档案

> 每个角色一张卡片。新章节出现新角色时必须新建卡片，不得在正文中临时编造。
> 即使本章无对白，"虚拟首语"必填——作为后续章节口吻锚点。

## 卡片模板

```
### {角色名}
- **身份**：
- **首次出现**：ch{NN}
- **外形**：身高 / 发色 / 标志特征（≤ 30 字）
- **口吻**（即使本章无对白也必填）：
  - 句长偏好：（短促 / 绵长 / 不定）
  - 标志性用词：
  - 禁用：（不会说的词）
  - **虚拟首语**（揣摩首次开口会说什么，3-5 句样本）：
    - "..."
    - "..."
    - "..."
- **性格底色**：（3 个关键词）
- **核心动机**：
- **角色弧线**：（起点 → 当前进度 → 目标终点）
- **关系网**：
  - {对方名}：{关系性质 + 当前张力}
- **状态变化日志**：
  - [ch01] 初登场：{状态}
- **物品与能力清单**：
- **禁忌**（必须可观测——具体动作而非抽象动机）：
```

> **禁忌示例**：
> - ✓ 好："绝不会主动破坏造景箱"（可观测的具体动作）
> - ✗ 差："绝不会轻易放弃"（抽象动机，不能验证）
