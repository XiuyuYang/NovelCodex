# 审校调用模板

## 初次审校
```
用 reviewer-{维度} 审校以下文件：
路径：{文件路径}
阶段：（蓝图/细纲/正文）
品质档位：{档位}
请输出完整审校报告，每个维度给出 1-5 分，含各维度评分表格和必改项。

评分规则：
5=优秀 / 4=良好 / 3=合格 / 2=低于预期 / 1=严重缺陷
```

## 验收
```
用 reviewer-{维度} 验收以下文件的修改：
路径：{文件路径}
阶段：（蓝图/细纲/正文）
品质档位：{档位}
这是第 {N} 轮修改后的版本。
你在上一轮中提出以下问题：{问题列表摘要}
请逐项验收，输出验收报告含通过/不通过结论。
```

## 全量终审
```
用 reviewer-{维度} 对以下文件进行全量终审：
路径：{文件路径}
阶段：（蓝图/细纲/正文）
品质档位：{档位}
这是全量终审轮次，请对文件进行完整重新审校。
每个维度给出 1-5 分，输出完整审校报告含各维度评分表格。
```

## 叙事压力测试
```
用 reviewer-plot-engineering 执行叙事压力测试：
路径：{文件路径}
阶段：正文
品质档位：{档位}
这是最终版正文的叙事压力测试。
请模拟两遍阅读效果，输出压力测试报告含通过/不通过结论。
```
