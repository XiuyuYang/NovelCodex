# 体裁画像 (Genre Profile)

本文档定义当前小说的维度权重配置。审校团根据此画像进行评分加权和通过判定。

## 使用方式

1. 创作开始时，用户设定当前小说的**体裁**和**品质档位**
2. Orchestrator 加载对应配置
3. 审校员输出各维度 1-5 分
4. Orchestrator 按档位阈值 + 体裁画像做出通过/修改/阻塞判定

---

## 四档品质系统

系统提供四个品质档位，控制审校通过门槛的松紧度。档位在创作开始时设定，整部小说统一。

| 档位 | 定位 | 核心均分要求 | 核心单维最低 | 重要单维最低 | 章节综合评分 |
|------|------|-------------|-------------|-------------|-------------|
| **低档** | 快速成文 | ≥ 2.5 | 允许到 1（< 1 阻塞） | 允许到 0（永不阻塞） | ≥ 2.5 |
| **中档** | 标准创作 | ≥ 3.5 | 允许到 2（< 3 阻塞） | 允许到 1（< 2 阻塞） | ≥ 3.5 |
| **高档** | 精品打磨 | ≥ 4.5 | 允许到 2（< 3 阻塞） | 允许到 1（< 2 阻塞） | ≥ 4.5 |
| **最高档** | 满分门禁 | ≥ 5.0 | 必须 5 | 必须 5 | ≥ 5.0 |

> **低档**适合练笔、过渡章节、探索性写作；**中档**为日常创作标准；**高档**用于关键章节、冲榜场景，追求文学品质；**最高档**用于全维度满分门禁，任何维度低于 5/5 都不通过。

## 永不降档铁律

品质档位（quality_tier）是**项目级**设定，写入 `runtime.json`。一旦确定，**不允许在创作过程中降档**。

错误处理：
- 任何阶段连续 5 轮验收仍不通过 → 强制回退本章 Phase 1（chapter-planner 重写蓝图）
- 任何章节压力测试不通过 → 必须回 Phase 2 重写细纲
- **不存在「超 N 轮自动降档」机制**

## 逻辑维度铁律（覆盖档位）

**所有档位下，逻辑维度（reviewer-logic）的全部子项必须 5/5 才能通过。**

| 档位 | 其他维度 core_min | 逻辑维度 |
|------|-------------------|---------|
| 低档 | 2 | **必 5** |
| 中档 | 3 | **必 5** |
| 高档 | 3 | **必 5** |
| 最高档 | 5 | **必 5** |

理由：作品其他维度可妥协（节奏/文采/AI味在低档放宽），但逻辑漏洞会让整部作品瞬间崩塌。逻辑维度阻塞时，不允许"超过 6 轮强制降档"绕过——必须由 chapter-planner 重写蓝图。

### 阻塞逻辑

得分 < core_min → 对应维度阻塞（不分档位，逻辑统一）

```
核心维度：评分 < core_min → 阻塞
重要维度：评分 < important_min → 阻塞
核心维度平均分 < core_avg → 建议优化（不强制阻塞）
```

| 字段 | 低档 | 中档 | 高档 | 最高档 |
|------|------|------|------|--------|
| `core_avg` | 2.5 | 3.5 | 4.5 | 5.0 |
| `core_min` | 2 | 3 | 3 | 5 |
| `important_min` | 1 | 2 | 2 | 5 |
| `chapter_score_min` | 2.5 | 3.5 | 4.5 | 5.0 |

## 预设体裁配置

各体裁的维度分级（核心/重要/增益）独立于品质档位。用户可任意组合 `current_genre` 字段：
- `current_genre: 通用小说`
- `current_genre: 奇幻/科幻`
- `current_genre: 悬疑惊悚`
- `current_genre: 纯文学`
- `current_genre: 喜剧/幽默`

以下预设仅描述**维度分级差异**（相对于通用小说默认），阈值由档位决定。

### 悬疑惊悚 (Thriller)

```
建议档位：中档或高档

差异（相对于默认）:
  [节奏] A.张弛分布 → 核心
  [节奏] G.信息释放 → 核心 (默认已核心)
  [剧情工程] G.信息不对称 → 核心 (默认已核心)
  [剧情工程] I.悬念管理 → 核心 (默认已核心)
  [一致性] G.叙事伦理 → 重要 (默认增益, 升级)
  [逻辑] G.第三條路 → 重要 (默认增益, 升级)
  [描写] E.展示vs告知 → 核心 (默认已核心)
  [对白] B.对话标签 → 核心 (默认重要, 升级)
  [语言] G.句法工程 → 增益 (维持)
  [节奏] I.时空体 → 增益 (维持)
```

### 纯文学 (Literary)

```
建议档位：中档或高档

差异（相对于默认）:
  [语言] G.句法工程 → 核心 (默认增益, 升级)
  [一致性] G.叙事伦理 → 核心 (默认增益, 升级)
  [节奏] J.审美距离 → 核心 (默认增益, 升级)
  [节奏] I.时空体 → 重要 (默认增益, 升级)
  [描写] B.比喻与意象 → 核心 (默认重要, 升级)
  [剧情工程] H.幽默侧向位移 → 增益 (维持)
  [对白] F.元叙事 → 重要
```
