# 生成与验收共同标准

标准版本：1.0。生成者、审核者、协调者使用同一冻结文件及 SHA256。以下是产物目标，不是固定的创作步骤。未获用户确认的审美偏好不加入硬门槛。

- S1 简洁完整：输出剧情框架，直接交代必要情绪和动机；每个采用版本有起因、过程和结果，无已知必要因果前提欠账。不要求文学描写、固定字数或每轮只能改一处。
- S2 因果与结局：事件、选择与后果能相互支持。改变资源、时间、能力、人物关系或信息条件时，检查其对主线结果的影响；可以改变旧结局或旧事实，但须同步改顺相关前因后果。没有精确数值不自动构成矛盾；若结果依赖未建立的条件，指出缺失的具体连接。
- S3 人物连续：基于既有经历、目标、利益、关系和当时认知发展选择。允许矛盾心理、失误和有依据的改变，优先利用现有角色，必要时可新增；不强制人人复出，不把性格标签写死。
- S4 世界与共同事件：当前版本内的时间、地点、尺度、能力、物件状态和客观事件不互相冲突。区分事实、人物所知、传言和推测。跨弧回改须检查相关原文；旧设定可明确修订，不可暗换而保留不兼容后果。
- S5 叙事收益：扩充须对选择、关系、因果、风险、认识或后续产生可说明的作用，不以新增字数或反转数为收益。允许支线与舒缓；不强制新增修仙战斗、感情线、悬念或经营情节的特定比例，不追求最短解法。
- S6 记忆忠实：正式人物、设定、依赖和伏笔记录来自采用后的剧情。显式事实的全部断言有同等强度的原文依据；推断标为推断，不把引用存在等同语义支持完整。草稿和未选分支不进入正式状态。
- S7 安全提交：局部包基于本轮冻结基线，审核后单一提交，保存旧快照；失败保留旧版。串行轮次读取前一轮结果，平行候选彼此隔离。

## 审核约定

审核每个阻断问题写明标准编号、事件原文、为何违反、影响范围；区分确定冲突、必要连接未交代和仅待量化条件。允许建议性改进，但新增审美要求仅属建议，不能否决本轮。发现此前未注意到的具体矛盾可按已有 S2/S3/S4 阻断，不需要预先枚举所有漏洞。

开轮时记录标准版本、文件散列、基线版本/散列和本轮简短目标；候选与审核均报告同一标准散列。中途不改单轮标准；若确需升级，结束或作废旧审核，再让生成和审核共同采用新版。内容相同与模型遵从是两件事，保存实际证据。
